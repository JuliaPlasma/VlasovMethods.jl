Plotting

Every plotting function is declared in src/plotting.jl and has its methods in the package extension VlasovMethodsMakieExt, which loading CairoMakie activates. Each returns a Figure and writes no file: a driver in scripts/ loads CairoMakie, calls these functions, and saves each Figure under a name of its own.

Distributions and series

VlasovMethods.plot_distribution — Function
plot_distribution(dist) -> Figure
plot_distribution(dist; xdomain, vdomain, nx = 100, nv = 100) -> Figure

A phase-space portrait of dist on one axis, x horizontally and v vertically.

Defined in a package extension: load CairoMakie to make it available.

using VlasovMethods, CairoMakie
fig = plot_distribution(dist)

The one-argument method takes a GridDistribution and draws dist.values as a single heatmap on the grid's own nodes, untransposed: the columns of the matrix are the v nodes, so the figure and the matrix have the same orientation.

The method with the two keywords takes a ParticleDistribution of one position and one velocity dimension and draws the weighted particle histogram on nx × nv cells of xdomain and vdomain. Cell (i, j) holds

\[F_{ij} = \frac{1}{h_x h_v} \sum_k w_k ,\]

summed over the particles that fall in it, with $h_x = (x_b - x_a) / n_x$ and $h_v = (v_b - v_a) / n_v$, so the histogram integrates to the total weight of the particles it keeps. A cell is half-open, [x_a + (i-1) h_x, x_a + i h_x) and likewise in v.

xdomain is periodic and x wraps into it. vdomain is bounded, and a particle outside it — v < v_a or v >= v_b — is dropped from the histogram rather than clamped into an end cell. A particle with a non-finite x, which the wrap cannot place, is dropped as well, and so is a particle with a non-finite weight, which would make its whole cell NaN or infinite. A distribution with no particles throws an ArgumentError, and so does a cell count that is not positive, or a domain that does not run from its lower to its upper end or has an end that is not finite.

There are no other keywords, and the two domains are required. Use the returned Figure to set a title, a size or an axis label.

VlasovMethods.plot_particles — Function
plot_particles(dist; xdomain, vdomain) -> Figure
plot_particles(SS, ts, p; xdomain, vdomain) -> Figure

The particles of a ParticleDistribution of one position and one velocity dimension, as a single scatter of (x, v).

Defined in a package extension: load CairoMakie to make it available.

using VlasovMethods, CairoMakie
fig = plot_particles(dist; xdomain = (0.0, 2π), vdomain = (-4.0, 4.0))

xdomain is periodic and x wraps into it. Every particle's velocity is plotted as it is, and the axis limits are set to xdomain horizontally and vdomain vertically, so a particle at v outside vdomain is left at that v and lies outside the axes. A distribution with no particles throws an ArgumentError.

The second method takes a Snapshots, and draws its saved state: the positions and the velocities of the one component, SS.X[1, :, ts, p] against SS.V[1, :, ts, p], as the scatter above, with x wrapped into xdomain. It plots the state that a march saved, so a frame of ts = saved_indices(nₛ)[1] shows the final state of the sweep. ts and p must index the saved times and the parameters, else an ArgumentError names the range it left.

There are no other keywords, and the two domains are required. Use the returned Figure to set a title, a size or an axis label.

VlasovMethods.plot_series — Function
plot_series(t, series; labels = nothing, xlabel = "t", ylabel = "",
    yscale = identity) -> Figure

One line per element of series against the abscissae t, on one axis.

Defined in a package extension: load CairoMakie to make it available.

using VlasovMethods, CairoMakie
fig = plot_series(ts, (x2, xmax); labels = ["x2", "xmax"], ylabel = "error", yscale = log10)
fig = plot_series(ts, (W_hfm, W_rom); labels = ["HFM", "ROM"], ylabel = "field energy")
fig = plot_series(μ, (γ_hfm, γ_rom); labels = ["HFM", "ROM"], xlabel = "parameter", ylabel = "γ")

series is any collection of vectors of length(t) values: the entries of the NamedTuple of trajectory_errors for one parameter, or a column of each entry for (nₚ, nₛ, nparam) input; the potential_error of each parameter; the field energies W of a full-order and a reduced march, the energy H of a conservative one, or its drift ΔH/H, against the saved times; or the growth_rate values of a sweep against the equation parameter. t holds the abscissa of each value, so one figure holds the quantities that share it.

labels names the lines. It is nothing, which draws no legend, or a collection with one label per element of series, in the same order, whose string is drawn as a legend of the axis. xlabel and ylabel label the axes. yscale is the scale of the y axis: identity, linear, or log10, to read a decaying error or values that span orders of magnitude.

Throws

  • ArgumentError when series holds no line, or a line holds no value, and when yscale is log10 and a line holds a negative value. A zero is accepted: it has no place on the axis, so it is drawn as a NaN, where its line breaks.
  • DimensionMismatch when a series is not as long as t, and when labels does not hold one label per series.

VlasovMethods.plot_groups — Function
plot_groups(t, groups; xlabel = "t", ylabel = "", yscale = identity,
    colors = (:blue, :orange, :green)) -> Figure

The lines of several groups against the abscissae t, on one axis, every line of a group in the group's colour, with one legend entry per group.

Defined in a package extension: load CairoMakie to make it available.

using VlasovMethods, CairoMakie
fig = plot_groups(t, ["HFM" => eachcol(W_hfm), "ROM" => eachcol(W_rom)]; ylabel = "W",
    yscale = log10)

groups is a collection of name => series pairs, such as a vector or a Dict, whose iteration order numbers the groups, and series any collection of vectors of length(t) values, such as the field energy of every sample of a sweep for one model. Group i draws each of its lines in colors[i] at the opacity 0.5, so that the lines of one group read as a band, and string(name) is the label of a legend entry of that colour in the axis' top right corner. xlabel and ylabel label the axes, and yscale is the scale of the y axis, as for plot_series.

Throws

  • ArgumentError when groups holds no group, when a group holds no line, or a line holds no value, and when yscale is log10 and a line holds a negative value. A zero is accepted, and drawn as a NaN, as for plot_series.
  • DimensionMismatch when a line is not as long as t, and when colors holds fewer colours than groups holds groups.

VlasovMethods.plot_damping — Function
plot_damping(runs, reference; title = "", colors = (:steelblue, :firebrick)) -> Figure

The logarithm of the field's first mode, $\log|E_1|$, of each run against t, with the peaks that its damping rate is fitted through as markers, and a dashed reference line, on one axis of a Figure of 1200 × 500 pixels.

Defined in a package extension: load CairoMakie to make it available.

using VlasovMethods, CairoMakie
run = (t = times, y = logE, peak_t = ts, peak_y = ys, label = "nv = 1025: γ = -0.1533")
fig = plot_damping([run], (t = [8.0, 40.0], y = y₀ .- 0.1533 .* ([8.0, 40.0] .- t₀),
    label = "γ = -0.1533"); title = "k = 0.50")

Each element of runs has the fields t and y, the series drawn as a line, peak_t and peak_y, its peaks drawn as markers of size 8, and label, whose string is the legend entry of its line. Run i is drawn in colors[i]. reference has the fields t, y and label, a line drawn black and dashed, such as the textbook rate laid through a peak, so that its slope compares with the peaks of each run. The legend is in the axis' bottom left corner. title is the axis' title.

Throws

  • ArgumentError when runs holds no run, or a run or the reference holds no value.
  • DimensionMismatch when the y of a run or of the reference is not as long as its t, when the peak_y of a run is not as long as its peak_t, and when colors holds fewer colours than runs holds runs.

VlasovMethods.plot_phase_space — Function
plot_phase_space(z, slices; xdomain, titles) -> Figure

The particles of a trajectory at the time slices slices, one scatter of (x, v) per slice in a row of panels of one Figure of 1500 × 400 pixels.

Defined in a package extension: load CairoMakie to make it available.

using VlasovMethods, CairoMakie
z = h5read(file, "z")
fig = plot_phase_space(z, [1, 67, 134, 201]; xdomain = (0.0, 1.0),
    titles = ["t = 0.0", "t = 6.6", "t = 13.3", "t = 20.0"])

z is the (2, npart, ntime) array of the trajectory that run!(::SplittingMethod, h5file) of a 1D1V model writes: z[1, :, s] holds the positions and z[2, :, s] the velocities at time slice s. Panel i draws slice slices[i], with the positions wrapped into the periodic xdomain, under the title titles[i]. Each particle keeps one colour in every panel: steel blue where its velocity at the first time slice, z[2, k, 1], is not negative, and fire brick where it is, so that the filamentation of each half of the cloud reads apart. Every panel is limited to xdomain horizontally and to [-v_max, v_max] vertically, with v_max the largest finite |v| of all the slices in slices rounded up to an integer, and only the first panel labels its v axis. A non-finite velocity draws no marker.

Throws

  • ArgumentError when z does not hold two rows, or holds no particle or no time slice, when slices holds no slice, when a slice is not a time slice of z, and when no slice in slices holds a finite nonzero velocity, so that v_max is zero.
  • DimensionMismatch when titles does not hold one title per slice.

VlasovMethods.plot_velocity_projections — Function
plot_velocity_projections(v, v̇, panels; vdomain) -> Figure

The right-hand side v̇ of a velocity-only collision model at the velocities v as a scatter, then one panel per element of panels with the particles' histogram, the spline projection and its derivative, in a row of panels of one Figure of 1600 × 450 pixels.

Defined in a package extension: load CairoMakie to make it available.

using VlasovMethods, CairoMakie
panels = map((1, length(t))) do s
    f = deepcopy(projection(z[:, s], dist, sdist))
    (v = z[:, s], f = f, df = derivative(f), title = "t = $(t[s])")
end
fig = plot_velocity_projections(v₀, v̇₀, panels; vdomain = (-10.0, 10.0))

projection writes into sdist and returns its spline, so a panel keeps a copy: without the deepcopy, every panel draws the last projection.

The first panel, titled "right-hand side at t = 0", draws v̇ against v with markers of size

  1. Each element of panels has the fields v, the particle velocities, f and df, two

callables such as a spline projection and its derivative, and title. Its panel draws the histogram of v on 80 equal bins of vdomain, normalised as a probability density, and f and df on 201 points of vdomain, df dashed; the first of these panels carries the legend in its top left corner.

Throws

  • ArgumentError when v, v̇ or the v of a panel holds no value, when panels holds no panel, and when vdomain is empty or reversed.
  • DimensionMismatch when v̇ is not as long as v.

The collision figures

VlasovMethods.plot_collision_distribution — Function
plot_collision_distribution(f, g; xdomain, vdomain, nx = 100, nv = 100) -> Figure

The initial distribution f and the final distribution g of a collision run, in two panels of one Figure, titled initial and final, with the Maxwellian of f drawn on each as a contour.

Defined in a package extension: load CairoMakie to make it available.

using VlasovMethods, CairoMakie
fig = plot_collision_distribution(f, g; xdomain = (0.0, 1.0), vdomain = (-10.0, 10.0))

f and g are ParticleDistributions of one position and one velocity dimension, and of one element type. Each panel is the weighted particle histogram of plot_distribution on nx × nv cells of xdomain and vdomain, with the same cells, the same normalisation and the same particles dropped, so each integrates to the total weight of the particles it keeps.

The contour is the Maxwellian that carries the mass, the momentum and the energy of f, evaluated on the cell centres,

\[M(x, v) = \frac{n}{\sqrt{2 \pi T}} \exp\left( - \frac{(v - u)^2}{2 T} \right) , \qquad n = \frac{W}{x_b - x_a} , \quad u = \frac{1}{W} \sum_k w_k v_k , \quad T = \frac{1}{W} \sum_k w_k (v_k - u)^2 ,\]

with $W = \sum_k w_k$, the sums running over the particles of f whose position, velocity and weight are finite. A collision operator that conserves mass, momentum and energy relaxes a spatially uniform f towards this Maxwellian, so the final panel shows how close g has come to it.

Throws

  • ArgumentError when nx or nv is not positive, when a domain does not run from its lower to its upper end or has an end that is not finite, when f or g holds no particle, and when f has no positive mass or no positive temperature, which leaves no Maxwellian to draw.

VlasovMethods.plot_drift — Function
plot_drift(t, (mass, momentum, energy); labels = ("mass", "momentum", "energy")) -> Figure

The relative drift of each conserved quantity against t, one line per quantity, on a logarithmic y axis.

Defined in a package extension: load CairoMakie to make it available.

using VlasovMethods, CairoMakie
fig = plot_drift(t, (mass, momentum, energy))

Each element of the second argument is the series of one quantity $Q$ at the times t, and its line is the drift relative to the initial value, $|Q(t) - Q(t_1)| / |Q(t_1)|$. labels names the lines in a legend, one label per quantity, in the same order; the default names three, so fewer or more quantities need their own.

The drift at t[1] is zero, which a logarithmic axis cannot show. A zero drift is dropped from a line that has a positive drift, as a pair whose time or drift is NaN or Inf is, and the rest of the line is drawn. The line of a quantity whose drift is zero at every time, a quantity conserved exactly, is drawn one decade below the smallest positive drift on the axis, or at the smallest positive value of the element type, floatmin, where no drift is positive. A series of one value has the single drift zero, and is refused. Where every value on the axis is the same c, as where each quantity is conserved exactly, the axis spans a decade on each side of c, within the positive finite Float64s. Makie's own limits would span the decades between c² and one, and c² is zero for floatmin of Float64, so the figure would not save.

Throws

  • ArgumentError when the second argument holds no quantity, when t or a quantity holds no value, when the initial value of a quantity is zero or not finite, so that its relative drift is not defined, when no pair of time and drift is finite, and when a drift is the single value zero.
  • DimensionMismatch when a quantity is not as long as t, and when labels does not hold one label per quantity; the message names the shorter one.

VlasovMethods.plot_error — Function
plot_error(t, err, closed) -> Figure

The error err of a run against its closed form, and the closed form closed itself, against t: one line each, labelled error and closed form, on a logarithmic y axis.

Defined in a package extension: load CairoMakie to make it available.

using VlasovMethods, CairoMakie
fig = plot_error(t, abs.(T_run .- T_closed), T_closed)

A pair whose time or value is NaN or Inf is dropped, and the rest of the line is drawn. A zero is dropped from a series that has a positive value; a series that is zero at every time is drawn one decade below the smallest positive value on the axis, or at floatmin of its element type where no value is positive, as plot_drift describes. A series of one value is drawn as a marker. Where every value on the axis is the same, as where both series are zero, the axis spans a decade on each side of it.

Throws

  • ArgumentError when t, err or closed holds no value, when no pair of t and err, or of t and closed, is finite, when err or closed holds a negative value, and when either is the single value zero: log10 has no value there.
  • DimensionMismatch when the three differ in length; the message names the shorter one.

VlasovMethods.plot_convergence — Function
plot_convergence(h, err) -> Figure

The error err against the cell width h, one marker per pair, on logarithmic axes, with the fitted line $C h^p$ and the exponent p in the y axis' label.

Defined in a package extension: load CairoMakie to make it available.

using VlasovMethods, CairoMakie
fig = plot_convergence([0.4, 0.2, 0.1, 0.05], errors)

p and $\ln C$ are the slope and the intercept of the least-squares line through the pairs $(\ln h_i, \ln e_i)$ whose h and err are positive and finite, and the label shows p to three significant digits.

A pair whose h or err is NaN or Inf is dropped, and so is a pair with a zero, which has no logarithm: it is neither drawn nor fitted. Where every error is the same value, as for an error that does not depend on h, the y axis spans a decade on each side of it, as plot_drift describes.

Throws

  • ArgumentError when h or err holds no value, when no pair of them is finite, when fewer than two pairs are positive and finite, when every h of those pairs is the same, so that no slope can be fitted, and when either holds a negative value.
  • DimensionMismatch when h and err differ in length; the message names the shorter one.

VlasovMethods.plot_cost — Function
plot_cost(cost, err) -> Figure

The error err of each run against its wall-clock cost cost, one marker per run, on logarithmic axes.

Defined in a package extension: load CairoMakie to make it available.

using VlasovMethods, CairoMakie
fig = plot_cost(seconds, errors)

A run whose cost or error is NaN or Inf is dropped. A run with a zero cost or error is dropped where that series has a positive value; a series that is zero in every run is drawn at floatmin of its element type. An axis whose every value is the same, such as an error that is zero in every run, spans a decade on each side of it, as plot_drift describes.

Throws

  • ArgumentError when cost or err holds no value, when no pair of them is finite, when either holds a negative value, when either is the single value zero, because log10 has no value there, and when no run that is left has both a place on the cost axis and a place on the error axis.
  • DimensionMismatch when cost and err differ in length; the message names the shorter one.
