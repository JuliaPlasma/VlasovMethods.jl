# Library

The library holds the docstring of every documented function and type of VlasovMethods, exported
or internal, in the order of the sections of the manual. An internal name is written with the
module, as `VlasovMethods.compute_coefficients`.

| [Distributions and projections](distributions.md) | distribution functions, initial conditions, projections |

| [Landau collisions](landau.md) | both Landau methods and their time integrators |
| [Reduction](reduction.md) | grid reduced tensors, reduced-order models, autoencoder frontends |
| [Dynamical low rank](lowrank.md) | low-rank distributions, the grid factor space, the factored fields, the projector splitting |
| [Plotting](plotting.md) | the plotting functions |
